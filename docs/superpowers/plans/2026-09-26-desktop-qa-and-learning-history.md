# 桌面实测与学习字幕记录

目标：用已安装的 Windows EXE 做实际界面和系统音频测试；吸收同类字幕工具中适合德语学习的可回看记录，并保持覆盖层轻量。

## 验收标准

- 从桌面快捷方式指向的安装版启动，在真实 Windows 桌面上确认设置窗口、预览字幕条、普通播放音频后的字幕条可见。
- 德语学习记录只保存已完成的字幕片段，能查看德语和可选原文、复制、清空；临时字幕更新和同段重复事件不能污染记录。
- 记录默认仅驻留当前进程内存，不保存录音、密钥或字幕到磁盘；容量有上限。
- 回归测试和实播测试通过，重建并安装 EXE，桌面入口指向新构建。

## 工作步骤

1. [x] 黑盒启动安装版，用 Windows UI Automation 检查设置、预览覆盖层及音频回采；修复测试播放器参数导致的假失败。
2. [x] 参考现有同类应用的可回看记录理念，在当前 Qt 设置窗口加有限容量的学习记录，采用现有控制器事件更新机制并写先失败的测试。
3. [x] 修复设置窗口关闭和记录清空边界，跑全量/实播/安装版验证，更新文档和快捷方式，复核 Git 工作区。

## 边界

- 具体游戏的反作弊/独占全屏、受保护视频、真人多口音、真实 Azure 付费连接仍需对应样本和账号；本轮不拿合成语音结果替代这些验收。
- Windows 官方按进程回采接口可作为后续音源方案，先不把未编译、未在游戏中验证的原生组件加入当前成品。
