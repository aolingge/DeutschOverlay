# Deutsch Overlay 可靠性复核计划

目标：针对 2026-09-26 已打包版本的实际使用问题继续修复，并复测完整 Windows EXE。现有设计与便携式文件夹发行方式不变。

## 验收边界

- 选定播放设备的共享模式声音进入本地识别，字幕能在 Windows 桌面窗口显示。
- 拖动提示、托盘入口、重复启动和设备恢复不会把用户留在不可操作的状态。
- 在线模式未经手动启用和配置不得上传音频；不使用真实凭据或产生云费用做自动测试。
- 具体商业游戏、受保护视频和真人录音需要对应样本才能验收，不以合成语音代替。

## Task 1：窗口与单实例入口

文件：`src/deutsch_overlay/overlay.py`、`app.py`、`single_instance.py`，对应 `tests/test_overlay.py`、`tests/test_app_smoke.py`、`tests/test_single_instance.py`。

- [x] 测试：安静时解锁位置提示持续可见；锁定或隐藏后恢复正常字幕计时。
- [x] 测试：设置最小化后托盘入口还原并激活；IPC 监听失败不会误报已有实例。
- [x] 仅在位置提示上停用自动隐藏，并让所有打开设置入口复用 `show_settings()`；单实例返回区分已有实例与监听错误。

## Task 2：弱语音与长句边界

文件：`src/deutsch_overlay/audio.py`，对应 `tests/test_audio.py` 和真实语音测试。

- [x] 测试：低音量已知语音仍进入 Silero；持续非语音音调仍被拒绝。
- [x] 测试：长于 7 秒的连续语音切片保留边界附近的短上下文，片段长度仍有上限。
- [x] 调整检测用音量归一化和强制切片方式；用系统播放 MP4 验证无回归。

## Task 3：在线连接与成品复测

文件：`src/deutsch_overlay/controller.py`、`engines/azure.py` 及对应测试。

- [x] 测试：无播放设备时不先启动 Azure；设备首帧到达后才开始在线会话；切换设备仍隔离旧字幕。
- [x] 实现在线启动顺序，确认限额/错误停止后不暗中重试收费会话。
- [x] 全量回归、真实 Windows MP4/覆盖层联动、依赖审计、最终 EXE 自检、快捷方式核对，结果写入 `docs/verification.md`。

## 未由本机自动测试替代的验收

- 指定游戏无边框全屏连续 15 分钟以及游戏德语语音 20 段。
- 英语和中文视频各 20 段真实语音的人工准确率评价。
- Azure 真实账号、网络与账单边界。
