# 设置与字幕操作改版

目标：保留现有识别、翻译和设置格式，重做 Windows 图形界面，让常用选择直接可见、易于操作。

- 主窗口使用清晰的左侧导航：字幕、外观、在线服务。字幕页优先提供双语模式、声音语言、播放设备、九宫格位置和即时操作。外观参数及云凭据分开显示。
- 用户选择后按固定底栏的“应用并预览”保存并看到真实字幕条。在线模式仍须每次运行手动启用；密钥继续只交给 Windows 凭据管理器。
- 解锁字幕位置时，字幕条显示轻量控制栏，能切换双语、打开设置和完成调整。锁定后控制栏消失，字幕条保持鼠标穿透。无需常驻悬浮球。
- 使用系统字体、清晰的层级、适当留白、可读对比度和可聚焦的文字按钮；不添加 UI 框架或外部代码。
- 保留现有快捷键、托盘菜单、预设、颜色及全部外观数值功能。
- 验收：新交互测试、现有回归测试、真实 Windows 窗口截图检查、安装版 UI Automation 预览和实际播放音频字幕验证。
